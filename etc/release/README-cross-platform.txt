Thunder client for Haven & Hearth
=================================

This package needs Java 17 or newer installed (https://adoptium.net).

To play:
  Windows:     run Thunder.bat
  Linux/macOS: run thunder.sh

Updates are automatic: each time you launch, the client checks the
latest Thunder release on GitHub and updates itself before starting.
If you are offline or the check fails, the current version just
launches as-is. To skip the check, set the environment variable
THUNDER_NO_UPDATE=1.

If you are on Windows and don't want to install Java, download the
Thunder-windows-x64.zip package instead - it has Java bundled.
